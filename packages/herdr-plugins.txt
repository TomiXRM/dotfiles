#   ref を書くとそのリビジョンに固定される。ref を書き換えると
#   run_onchange が再実行され、そのバージョンへ入れ替わる。

# 更新: herdrに `plugin update` が無いため再インストールが更新手段。
#   HERDR_PLUGINS_REFRESH=1 chezmoi apply  で一覧を全て入れ直す。
#
# 注意: install時に各リポジトリのbuildコマンドが実行される。信頼できる
#   リポジトリだけを列挙すること。
